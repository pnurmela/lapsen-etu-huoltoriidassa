# Liite B – Vanhemman yhden sivun toimintakortti

## Neljä vaihetta: turvallisuus → palvelut → päätökset → oikeussuoja

Tämän toimintakortin tarkoitus on auttaa vanhempaa keskittymään lapsen konkreettisiin tarpeisiin ja oikeisiin viranomaisprosesseihin vaikeassa erotilanteessa.

Hallintolain perusteella viranomaisen on käsiteltävä asia ilman aiheetonta viivytystä ja annettava pyynnöstä arvio päätöksen ajankohdasta. ([Finlex](https://finlex.fi/fi/lainsaadanto/saadoskokoelma/2003/434?utm_source=chatgpt.com))

---

## 1. TURVALLISUUS

Kysy ensin: **onko lapsi tai joku muu juuri nyt vaarassa?**

Toimi heti, jos kyse on esimerkiksi:
☐ väkivallasta tai välittömästä väkivallan uhasta  
☐ vakavasta uhkailusta  
☐ vainosta tai seuraamisesta  
☐ lapsen luvattoman poisviemisen konkreettisesta uhasta  
☐ vakavasta päihtymyksestä lapsen hoitotilanteessa  
☐ lapsen vakavasta itsetuhoisuudesta  
☐ lapsen kiireellisestä terveydenhuollon tarpeesta  
☐ tilanteesta, jossa kukaan ei pysty turvallisesti huolehtimaan lapsesta.  

### Oikea reitti
* **Hätätilanne → 112**
* Tarpeen mukaan lisäksi:
  ☐ poliisi  
  ☐ sosiaalipäivystys  
  ☐ lastensuojelu  
  ☐ terveydenhuolto  
  ☐ turvakoti.  

### Älä tee tässä vaiheessa
* älä jää odottamaan muistutusta tai kantelua
* älä kuulustele lasta yksityiskohtaisesti
* älä pyydä lasta keräämään todisteita
* älä järjestä turvallisuusriskissä vanhempien yhteistä kohtaamista vain sovinnon vuoksi.

## 3. PÄÄTÖKSET

### Älä tyydy epäselvään suulliseen vastaukseen
Jos viranomainen sanoo esimerkiksi:
* *”Tätä ei voida järjestää.”*
* *”Toinen vanhempi ei suostu.”*
* *”Tämä kuuluu huoltoriitaan.”*
* *”Meillä ei ole tällaista palvelua.”*

**Kysy:**
1. Onko tämä hakemukseni ratkaisu? (kyllä / ei)
2. Kuka on toimivaltainen päätöksentekijä?
3. Saanko asiasta kirjallisen päätöksen? (kyllä / ei)
4. Mihin lainkohtaan ratkaisu perustuu?
5. Miten voin hakea muutosta?

### Kirjallisessa päätöksessä tarkista
☐ mitä hakemukselle päätettiin  
☐ kuka päätöksen teki  
☐ mitä tosiseikkoja käytettiin  
☐ mitä asiakirjoja ja selvityksiä käytettiin  
☐ miten lapsen oma näkemys huomioitiin  
☐ mitä lainkohtia sovellettiin  
☐ miten muutosta haetaan  
☐ mikä on muutoksenhaun viimeinen päivä.  

> **Tärkeä sääntö:** Älä päättele muutoksenhakuaikaa muistista. Noudata päätöksen mukana annettua muutoksenhakuohjetta.

## 4. OIKEUSSUOJA

Valitse keino sen mukaan, mitä haluat saada aikaan:

| Tavoite | Oikea keino |
| --- | --- |
| Haluan lapselle palvelun | Hakemus |
| Haluan kielteisen ratkaisun arvioitavaksi | Oikaisuvaatimus tai valitus |
| Viranomainen ei tee päätöstä | Kirjallinen päätöspyyntö |
| Menettely on epäasiallista tai puutteellista | Muistutus |
| Haluan ulkopuolisen valvontaviranomaisen arvioivan menettelyä | Kantelu |
| Asiakasmerkintä on virheellinen | Oikaisu- tai täydennyspyyntö |
| Asiakirjaa ei anneta | Pyydä muodollinen tiedonsaantipäätös |
| Huolto tai tapaaminen on ratkaisematta | Lastenvalvoja tai käräjäoikeus |
| Voimassa olevaa tapaamisratkaisua ei noudateta | Täytäntöönpanon arviointi |
| Nykyinen tapaamisratkaisu ei enää sovi lapsen tilanteeseen | Muuttamishakemus |
| Epäilen rikosta | Poliisi |
| Tarvitaan suojaa vakavalta häirinnältä tai uhkalta | Lähestymiskielto |

## 5. PIDÄ PROSESSIT ERILLÄÄN

Älä käsittele kaikkia riitoja yhtenä kokonaisuutena:
* **Lapsen huolto ja tapaamiset** → lastenvalvoja / käräjäoikeus
* **Lapsen palvelut** → sosiaalihuolto / lastensuojelu / terveydenhuolto
* **Koulun tuki** → opetuksen järjestäjä
* **Varhaiskasvatuksen tuki** → varhaiskasvatuksen järjestäjä
* **Elatus** → lastenvalvoja / käräjäoikeus / Kela tilanteen mukaan
* **Omaisuus ja ositus** → oma erillinen prosessi
* **Rikosepäily** → poliisi
* **Henkilötiedot** → rekisterinpitäjä / tietosuojavaltuutettu

* **A.** oma havainto
* **B.** lapsen kertomus
* **C.** toisen vanhemman kertomus
* **D.** ammattilaisen havainto

## 8. ÄLÄ TEE LAPSESTA RIIDAN TODISTAJAA

Lapsen ei pitäisi joutua:
☐ valitsemaan vanhempaa  
☐ välittämään viestejä  
☐ raportoimaan toisen kodin tapahtumia  
☐ nauhoittamaan toista vanhempaa  
☐ kirjoittamaan aikuisen sanelemaa lausuntoa  
☐ toistamaan samaa kertomusta tarpeettomasti eri aikuisille  
☐ päättämään yksin asiasta, jonka ratkaiseminen kuuluu aikuisille.  

Lapsen mielipide voi olla erittäin merkityksellinen, mutta sen selvittäminen ei tarkoita, että lapselle siirretään vastuu huolto- tai tapaamisratkaisusta.

2. Mikä osa kuuluu?
3. Mitä teette lapsen oman palvelu- tai turvallisuustarpeen arvioimiseksi?
4. Kuka vastaa asian käsittelystä?
5. Milloin saan vastauksen tai päätöksen?

## 10. KUN VANHEMPIEN KERTOMUKSET OVAT RISTIRIIDASSA

Älä yritä ratkaista kaikkea lähettämällä viranomaiselle satoja sivuja viestejä. Lähetä ensin:
1. 1–2 sivun neutraali tilannekooste
2. aikajana
3. 3–5 tärkeintä asiakirjaa
4. täsmällinen pyyntö siitä, mitä viranomaisen pitäisi ratkaista.

> **Esimerkiksi:** *”Vanhemmat antavat tapahtumasta ristiriitaiset kuvaukset. Pyydän selvittämään lapsen oman näkemyksen sekä hankkimaan koululta tapahtumaa koskevat havainnot. Pyydän tämän perusteella arvioimaan lapsen tuen tarpeen.”*

## 14. YHDEN MINUUTIN TARKISTUS

Jos tilanne alkaa jälleen tuntua sekavalta, kysy vain nämä:
* **TURVALLISUUS:** Onko lapsi juuri nyt turvassa?
* **PALVELUT:** Mitä lapsi tarvitsee juuri nyt?
* **PÄÄTÖS:** Kuka on velvollinen ratkaisemaan asian?
* **OIKEUSSUOJA:** Miten ratkaisun tai toimimattomuuden voi saada arvioitavaksi?

> **Muistisääntö:** Älä yritä voittaa koko huoltoriitaa yhdellä viranomaiskirjeellä. Ratkaise yksi lapsen kannalta konkreettinen kysymys kerrallaan: **turvallisuus → palvelu → päätös → oikeussuoja**.

Seuraava liite on Liite C – päätös- ja määräaikataulukko, jossa koko prosessin rinnakkaiset asiat saadaan yhdelle sivulle: mikä on vireillä, kenellä, milloin määräaika päättyy ja mikä on seuraava oikeussuojatoimi.
